# .NET Senior Interview Playbook

## What this repository is

A permanent, structured knowledge base for senior-level .NET and full stack interview preparation. Designed for long-term use, not just short-term study.

## Who this is for

- Senior software engineers (8–15+ years experience)
- Backend-heavy full stack developers
- Engineers preparing for technical interviews or role transitions

## What this repository covers

- C#
- .NET & CLR
- ASP.NET Core
- Entity Framework Core
- SQL & Databases
- Angular
- System Design
- Performance Optimization
- Architecture Patterns
- Cloud & DevOps

## How this repository is structured

- Topic-based organization (not week-based)
- Difficulty-based progression: Basics → Intermediate → Advanced
- Clear separation: learning, interview prep, real-world notes
- Consistent structure across all topics for easy navigation

## How to get started

- **Beginner path:** Start with 01-basics in each topic
- **Intermediate path:** Focus on 02-intermediate and 03-advanced
- **Senior revision path:** Use 04-interview-questions and 12-revision for rapid review

## How to use this repo for interview preparation

- Follow the learning path for each topic
- Use interview question folders for targeted practice
- Review real-world notes for practical insights
- Use revision sheets for last-minute prep

## How this repo should be maintained long-term

- Add new topics as technology evolves
- Update real-world notes with production experiences
- Keep interview questions current with industry trends
- Maintain consistent folder and file structure

## Disclaimer

This is not exam prep or a shortcut guide. The focus is on real engineering understanding, depth, and practical skills for senior roles.
