# Interview Question Framework

## Purpose of this framework

- Simulate real senior-level interviews
- Enforce depth-based answers
- Avoid shallow or memorized responses
- Provide consistent structure across all topics

---

## How interviewers ask questions in reality

- One main question to start
- Multiple layered follow-ups based on your answers
- Progressive depth probing to test limits of understanding
- Scenario-based variations to assess real-world thinking

---

## Standard Question Structure

For every interview question, define the following sections:

### Question

- Clearly worded technical or design question

### Priority

🟥 Must Know  
🟨 Should Know  
🟩 Nice to Know

### Difficulty Level

- Beginner
- Intermediate
- Senior

### What the interviewer is evaluating

- Knowledge
- Depth
- Experience
- Decision-making
- Communication

### Expected answer depth

- What is minimum acceptable
- What is strong
- What is exceptional

### Common weak answers

- Typical surface-level responses
- Memorized explanations
- Red flags

### Follow-up questions

- Deeper technical probes
- Edge-case questions
- “What if” scenarios

### Real-world discussion prompts

- Production failures
- Scaling issues
- Performance bottlenecks
- Trade-offs

---

## Ideal Answer Framework (Mandatory)

Every answer should follow this order:

1. Short definition (1–2 lines)
2. Internal working / flow
3. Real-world example
4. Trade-offs and limitations
5. Final summary

---

## Interviewer Red Flags

Examples:

- Jumping straight to code
- No understanding of internals
- Inability to explain trade-offs
- Overuse of buzzwords
- No production examples

---

## How to practice using this framework

- Self-practice: Write and review your answers using the structure
- ChatGPT mock interviews: Simulate Q&A sessions
- Peer interviews: Practice with colleagues for feedback
- Recording answers: Listen for clarity, depth, and structure

---

## How to add new interview questions

- File naming convention: Use clear, topic-based names (e.g., async-await-questions.md)
- Where questions should live: 04-interview-questions folder inside each topic
- Required metadata: Priority, difficulty, evaluation criteria
- Consistency rules: Follow the standard structure and answer framework for every question

---

Rules:

- No answers should be memorized.
- Understanding and reasoning matter more than syntax.
- Depth matters more than coverage.

---

Do NOT:

- Add technology-specific questions
- Add code samples
- Add example answers

This file defines standards only.
