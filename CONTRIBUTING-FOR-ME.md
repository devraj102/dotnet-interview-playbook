# How to Add Content to This Repository

## Folder rules
- Never change existing structure
- Follow numeric ordering
- One topic per folder

## File creation rules
- Use templates only
- Do not mix difficulty levels
- Do not mix theory and interview questions

## Naming conventions
- kebab-case filenames
- short, descriptive names

## Quality checklist before adding content
- Level defined
- Priority tagged
- Interview relevance clear
