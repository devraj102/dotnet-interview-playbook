# C# Basics

## What “C# Basics” really means for interviews

- Core execution flow and language fundamentals
- Not just syntax, but how C# runs on .NET
- Foundation for all higher-level topics

## Topics covered in basics

- CLR, JIT, and execution pipeline
- Types and variables
- Control flow
- Basic OOP

## When to move to intermediate

- When you can explain execution flow without notes
- When you can answer basic interview questions confidently

## Common beginner mistakes

- Memorizing syntax without understanding execution
- Ignoring the role of the CLR
- Overlooking type safety and managed code concepts
