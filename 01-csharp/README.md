# C#

## Why C# matters in backend interviews

- Core language for .NET backend development
- Used in enterprise, cloud, and high-scale systems
- Interviewers expect strong fundamentals, not just framework usage

## What interviewers expect at different levels

- **Beginner:** Understand execution flow, basic syntax, and type system
- **Intermediate:** Grasp OOP, error handling, collections, and LINQ
- **Senior:** Deep knowledge of internals, performance, and runtime behavior

## Learning path overview

- 01-basics: Execution, types, control flow, OOP
- 02-intermediate: Collections, LINQ, error handling, async
- 03-advanced: Performance, internals, advanced patterns
